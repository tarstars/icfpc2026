## The correction that made it work

The user spotted in the editor that pathfinder's rooms were all stacked
vertically with the width unused, and suggested moving them right. I
briefed an agent on that — and **my brief's premise was wrong.**

**pathfinder scores `footprint x ticks`, not area.** The agent built the
pure re-pack first: box 947, preflight 7/7 — and it scored
**4,441,102,966,537, WORSE than live**, because pipes four times longer
raised avgTicks from 3.08M to 4.95M. **Pipe length is delay, and delay is
half the score.**

So they measured per-pipe traffic instead of guessing:

```text
room0 <-> rooms 1/2/3   ~1,900-2,060 crossings each   HOT, must not move
rooms 4/5/6                264-375 crossings          cold, free to travel
```

Then moved only the cold rooms plus room2 (the 138-tall height driver),
leaving rooms 0/1/3 and the four hot-loop pipes **byte-identical**.
Result: 431x960, footprint 921,600 from 1,276,900, **-18.7%**.

**The lesson: on a footprint-x-ticks problem, re-packing must be traffic-
weighted.** Moving a room is free only if its pipes are cold.
