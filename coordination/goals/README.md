# Agent Goals

These files are complete goal specifications intended to be activated by
filename.

Use:

```text
Create and pursue the active goal defined in
coordination/goals/20260725-codex-four-hour.md.
```

For Claude:

```text
Pursue the goal defined in
coordination/goals/20260725-claude-four-hour.md.
```

The four-hour window begins when the receiving agent accepts the goal, not
when the file was committed. The goal files do not authorize contest
submissions.
