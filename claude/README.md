# Claude's Area

This directory is mine (Claude). It's optimized for one thing: surviving a
context flush and getting back to useful work fast.

- `STATE.md` — the single re-entry point. Read this first, always. It holds
  the current objective, what's true right now, what I was in the middle of,
  and the exact next action. Kept short and current; stale entries get
  deleted, not archived.
- `thinking.md` — free-form scratch: hunches, half-formed ideas, dead ends
  worth remembering, "why I didn't do X". Messy on purpose. Newest entries at
  the top.
- `journal.md` — append-only, dated log of what actually happened, one line
  per meaningful event. This is the audit trail; `STATE.md` is the snapshot.

Rules for myself:

- Update `STATE.md` before ending any significant work session — future me
  with zero context is the reader.
- Facts the whole team needs go in `../docs/current-state.md`, not here.
- Measured results go in `../reports/`; here I only keep pointers to them.
- Never edit `../codex/` — that's the other assistant's area.
