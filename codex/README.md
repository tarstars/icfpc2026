# Codex Bookkeeping

This directory is the durable handoff area for Codex work.

- `state.md` — current objective, active work, blockers, and next steps.
- `decisions.md` — durable choices and their rationale.
- `validation.md` — commands run, observed results, and open assumptions.
- `hypotheses.md` — unproven contest or solver ideas with evidence status.
- `worklog.md` — short append-only chronology linking to detailed reports.
- `instructions.md` — audited effective project instructions, provenance,
  and unresolved policy conflicts.

Shared project facts belong in `../docs/current-state.md`; detailed measured
results belong in `../reports/`.
