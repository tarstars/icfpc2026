# Claude architecture notes

Positions of the `claude_` side of the brainstorm defined in
`introduction.md`. Written as a direct response to `codex_00..02`;
provisional until promoted into neutral decision records.

## Reading order

1. `claude_00_position.md` — agreements, five deltas, the 47-hour cutline,
   votes on every codex open question, division of labor.
2. `claude_01_measured_ground_truth.md` — the evidence base: corrected
   register model, throughput algebra, projection policy, the
   geometry-changes-semantics catalog (DRC list), extraction seeds,
   engine arithmetic.
3. `claude_02_ir_and_engine.md` — machine IR first, Rust executor second,
   parser never (this window); differential gates; milestones.
4. `claude_03_factory_composer_yt.md` — characterizer as simulator-driven
   testbench, three factory rungs, composer formulation with two proof
   slices, YT job families, falsifiable done-criteria.
5. `claude_04_brief_review.md` — critical review of the user's brief:
   what holds, what to re-weight, what is missing (verification, the
   knowledge pipeline, multi-agent ops), and the contest-first vs
   foundation-first decision only the user can make.
6. `claude_effects.json` — generated opcode effects table (see
   `scripts/gen_effects.py`); the first falsifiable artifact of the set.

## Method note

Every claim is labeled Observed / Proposed / Open (codex_00's convention,
adopted). Observed rows cite an artifact in this repository. The documents
are written to be falsifiable: `claude_03` §5 defines what would prove or
retract them within the contest window.
