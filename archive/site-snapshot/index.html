ICFP Programming Contest 2026 — offline snapshot

Captured 2026-07-27, roughly 08:37–09:00 UTC, while the contest was still running (it ended 12:00 UTC that day). Team wheezards.

This page is a plain-HTML index and works from file://. The captured website itself does not. It is a single-page app that loads ES modules and WebAssembly, both of which browsers block over file://. Start the bundled server instead:

python3 serve.py  →  http://localhost:8000/

Run it from the directory that contains this file. See RESTORE.md for the details.

The captured site

  • site/ — index.html, all 37 JS chunks, CSS, the four Lato fonts, icons, and the littleman.wasm engine. Served by serve.py.
  • engine/ — the pretty-printed engine embed JS, for reading rather than running.

Contest data (plain JSON, browsable from file://)

  • problems/index.json — all 20 problems with their UUIDs; one file per problem alongside it, each with the statement, I/O spec, scoring and public tests.
  • standings/index.json — frozen standings, one file per graded problem (16 of them), plus our own row in each.
  • api/index.json — the raw public API captures, including the overall leaderboard and the contest clock.
  • submissions/index.json — our 105 submission response records, and the per-problem originals next to it.

Provenance
