# History Lesson Program Variants

Each generated candidate is preserved as `history_NN.man` and described in
`variants.json`. Older candidates are not overwritten when their encoding or
geometry changes.

`history_00.man` records the first radix-packed layout. The contest server
rejected it because vertically aligned backticks paired across dot padding.

`history_01.man` uses fixed-width slots whose vertical backtick pairs are
adjacent and therefore unambiguously legal. It passed the live judge.

`history_02.man` transposes the tape into vertical columns (radix 77, 17-digit
fields, 8 ASCII pieces, 3 dictionary tokens) and decodes it with a
non-destructive conditional-add chain, shrinking the box to 85x85 =
7,225. Generated by `src/littleman/history_small.py:build_history_small`;
the live submission passed 1/1 at score 7,225.

`history_03.man` uses 56 short dictionary tokens and an asymmetric lookup:
the 1,812-symbol main stream is packed into 204 radix-128 words, while a
cyclic 128-value tape maps each symbol to either one ASCII value or a packed
token. The same radix-128 splitter emits both forms. It occupies 84x84,
passes the public case in 1,783,519 ticks, and has local footprint score
7,056. Generated by
`src/littleman/history_compact.py:build_history_compact`.
