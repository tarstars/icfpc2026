## Architecture

The program shifts each input by 10001, placing real values in `1..20001`.
Sixteen identical stages each retain the maximum of their register and
incoming value while forwarding the minimum. This leaves the values stored in
descending order through the pipeline.

Sixteen `20002` tokens flush the registers. The gate discards the first 16
pipeline warm-up zeroes, decodes the following `n` sorted values, and emits
them. A trailing `-1` token resets every stage to zero before the next round.
The stages form a compact 4x4 serpentine chain.
