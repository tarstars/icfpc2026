# Packet Reassembly insertion-return shortcut

Date: 2026-07-27

Status: accepted live, 20/20.

## Candidate

`tcp_09` preserves the complete `tcp_08` packed-window machine, its 31×31
layout, and all pipe endpoints. It changes two blank cells in controller C:

| Rendered cell | C interior | New glyph | Purpose |
| --- | --- | --- | --- |
| `(28, 3)` | `(10, 2)` | `^` | leave the westbound insertion return |
| `(22, 3)` | `(4, 2)` | `>` | rejoin the eastbound main path |

The main entry already walks east through `(22, 3)`, so `>` is neutral there.
After an insertion, the return path reaches `(28, 3)` while walking west;
turning north and rejoining at `(22, 3)` removes four executed cells per
stored packet. No arithmetic, branching, register use, pipe, or room changes.

The exact artifact is `submissions/tcp/tcp_09.man`, generated by
`littleman.tcp_hotpath:build_tcp_hotpath`.

## Validation

`uv run pytest tests/test_tcp_hotpath.py tests/test_tcp_fast.py -q` passed
31 tests. The focused suite proves:

- deterministic generator/artifact parity and the exact SHA-256;
- exactly the two intended text differences;
- byte-identical pipe paths and identical resolution for all 35 `r`/`s`
  cells, including all 18 in controller C;
- 6/6 public cases with the exact tick vector above;
- six directed boundary workloads, including `n=1`, a full 16-packet window,
  immediate loss, in-order `n=48`, and reversed blocks;
- 768 deterministic differential fuzz streams.

The composite preflight reported `READY TO SUBMIT`, with a server-compatible
layout and pipe lengths `[2, 2, 4, 4, 5, 7, 15]`. Ruff lint and format checks
passed.

A separate full differential run judged 15,000 generated streams with both
machines (30,000 simulations, 70.85 seconds, 33,440 KiB maximum RSS):

| Baseline / candidate | Count |
| --- | ---: |
| pass / pass | 14,992 |
| pass / fail | 0 |
| fail / pass | 0 |
| fail / fail | 8 |

All eight common failures were inherited `tcp_08` wrong-output cases:
`(0, fuzz1028)`, `(0, fuzz1834)`, `(0, fuzz2448)`, `(0, fuzz4247)`,
`(83, fuzz517)`, `(83, fuzz1168)`, `(20260727, fuzz2917)`, and
`(20260727, fuzz4021)`. Thus this experiment does not claim that the packed
architecture is universally correct; it establishes that the shortcut adds
no observed regression among 14,992 baseline-passing streams.

An independent agent reproduced the same 14,992/0/0/8 matrix, public ticks,
unchanged bindings, and 3.076% reduction before release.
